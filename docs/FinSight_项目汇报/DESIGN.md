# DESIGN.md — FinSight 酒研助手 项目汇报

> 风格路由判定：项目汇报 / 技术分享场景，**不属于**学术答辩、商务咨询、党政红金三类垂直领域 → 走通用设计原则（universal-only），本文件为最终设计宪法。

## 0. 画布与母版

- 画布：**1280 × 720**，全部页面统一。
- **A · 标题块**：y 0–120px，高 120（内含上 padding 20）。主标题 34px bold，左对齐，x 起点 72。右上角可选一行 14px 章节标记（如 `01 / 三条链路`），位置全篇一致。
- **B · 内容区**：y 120–660px，高 540。所有正文、图表、卡片只在此区内。
- **C · 页脚条**：y 660–720px，高 60（含下 padding 20）。左侧 13px 项目名 `FinSight · 白酒行业智能投研`，右侧 13px 页码 `NN / 12`。封面、章节扉页、结束页省略 C 区。
- 左右安全边界：x 72 – 1208（左右各 72）。

## 1. 色彩系统（4 色，不新增）

| 角色 | HEX | 语义 |
|---|---|---|
| 主色 · 深海军蓝 | `#0E1B2E` | 深色页背景、大色块、标题栏底 |
| 辅色 · 中蓝 | `#2F5D9E` | 卡片背景、图表第二系列、分隔线、次级结构 |
| 强调 · 金 | `#C8A24A` | 巨型数字、关键数据、页码高亮、焦点下划线 |
| 中性 · 米白 | `#F5F1E8` | 深底上的文字；浅色页的背景 |

- **文本色**：深底用 `#F5F1E8`（主）/ `rgba(245,241,232,0.62)`（次）；浅底用 `#0E1B2E`（主）/ `rgba(14,27,46,0.62)`（次）。
- **面积分配**：主色 ≤ 60%，辅色 ≤ 30%，强调色 ≤ 10%（Hero 页可到 18%），其余为中性。
- **节奏**：P01/P03/P06/P07/P12 为深底（主色压满），P02/P04/P05/P08/P09/P10/P11 为浅底（米白）——深底 5 页、浅底 7 页，交替出现，避免全篇色彩雷同。
- **渐变**：`linear-gradient(135deg, #0E1B2E 0%, #2F5D9E 100%)` 仅用于封面/章节扉页的底；卡片不用渐变，靠 1px 描边 + 阴影分层。
- **半透明**：章节扉页背景图 `opacity: 0.28`；封面 0.55 并叠 `rgba(14,27,46,0.55)` 蒙版；卡片阴影 `0 6px 22px rgba(14,27,46,0.10)`。

## 3. 信息密度基线

- 常规内容页正文字数 ≥ 180，留白 ≤ 35%；本稿按 180–260 字控制。
- 卡片填充率 ≥ 85%，卡片尾部元素 `marginTop: auto` 钉底。
- 横向兄弟卡三段（标题 / 正文 / 尾注）y 轴等高对齐。
- 每页至少 1 个视觉锚点：≥ 48px 元素 或 ≥ 40% B 区面积的图/色块。

## 4. 配图与图示

**本稿全部使用矢量方案，不调用 AI 生图**（避免额外积分消耗，且技术汇报用抽象几何比摄影更克制）。

| 等级 | 用途 | 页面 | 规格 |
|---|---|---|---|
| L1 | 深色页的抽象几何底纹 | P01、P03、P07、P12 | 内联 `<svg>` 满版：金色细线网络 / 同心弧 / 细网格，`opacity 0.18–0.30`，叠在深蓝渐变之上 |
| L1 | 架构/链路图示 | P04 对比流程、P05 架构、P08 检索链路、P09 双层结构 | 内联 `<svg>`，按 B 区 ≥ 40% 绘制，线宽 1.5–2px |
| L1 | 数据图表 | P10 横向条形 + RAGAS 分数 | `Chart`（barChart + barDirection='bar'） |
| L3 | 页脚项目名 | 全部内容页 | 13px 文字，不用图片 |

- 全部页面零位图，`assets/` 保持为空。
- 视觉统一手段：同一套金色细线（`#C8A24A`）+ 深蓝底（`#0E1B2E`），构图只用「斜向网络 / 同心弧 / 横向层级」三种母题。

## 6. 自检清单（逐页提交前）

1. A 区标题 34px、x=72、y 基线一致；C 区页码 `NN / 12` 位置一致。
2. 本页只出现上述 4 个 hex 与 2 套字体。
3. 存在 ≥ 48px 视觉锚点，且锚点周围 ≥ 40px 呼吸空间。
4. 与上一页版式不同（版式清单按映射表执行）。
5. 留白不超上限；卡片填充率 ≥ 85%，尾注钉底。
6. 含数据的页必须有"数据 + 判断"两段式，禁止只摆数字。
